# 待確認位置

座標可疑、但自動比對無法定案的場站。確認後把座標寫進 `data/coord-overrides.json`
（key＝`縣市|場站名`，或直接用**場站 id** 當 key；id key 優先。同名場站一定要用 id，
否則一個名稱 key 會同時套到兩筆），並從本檔移除。

## 判定方式

三個獨立來源互比，落差大＝可疑：

| 來源 | 定位對象 | 典型失效 |
| --- | --- | --- |
| Nominatim / OSM | 地址門牌（`geocode-carmochi.mjs`，結果存 `data/geocode-cache.json`） | 門牌不存在就退成整條路的中心；「對面／旁」失真；路名撞名跨區 |
| NLSC 國土測繪中心 | 政府門牌坐標（`geocode-fallback.mjs`） | 門牌本身對，但停車場不在門牌上 |
| Autopass POI | **停車場實體**（`api.autopass.xyz/v3/pois`，`scrape-autopass.mjs`） | 冷門場站未收錄；同名多筆 |

Autopass 定位的是停車場本身而非地址，可信度最高，優先採用。
品牌來源自帶官方座標者（嘟嘟房地圖連結內嵌的 X/Y、台灣聯通、ViVi PARK）以官方值為準，
不要用 override 壓過去——官方後來補上座標時，記得把當初的補校 override 移掉。
